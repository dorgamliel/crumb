# Crumb

A Hebrew-first, mobile-first food magazine.

- `crumb/` holds the app source (React + TypeScript + Vite), its content and the nightly content pipeline. See `crumb/README.md` and `crumb/docs/ARCHITECTURE.md`.
- `docs/` holds the built site. GitHub Pages serves it from `main` / `docs` at https://dorgamliel.github.io/crumb/.

Crumb used to live inside `dorgamliel/ra`. It was moved here, with its history, on 2026-11-10.
